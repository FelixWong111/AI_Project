## 阶段 2：P06 检测观察接口

复用 Ultralytics 官方 API，新建 P06 专属加载/推理模块，消费冻结配置，输入 uint8 BGR 帧，返回原图 xyxy、类别 0–5、原始检测置信度和唯一 detection_id。仅按最终保留的对象逐类计数，counts 必须包含 0–5 并与对象列表完全一致；空检测返回六类零计数，不能添加 ID 0 框。预期数不得影响目标检测输出。

不修改 P07/P08 公共实现。先交付检测观察值，不复制正式 PASS/FAIL 判定，不自动引入跨类别 NMS、尺寸阈值或未确认拒识规则。低置信/粗细混淆的处理如需改变，另有明确规则和验收后再做。

验收：实际 GPU 图片推理；空结果、非法输入、权重/类别不符、GPU 不可用拒绝；框与计数一致；原图坐标正确；相同图像重复输出稳定；记录 CUDA 同步。单元测试可用合成预测验证格式与计数，不能代替模型性能证据。
