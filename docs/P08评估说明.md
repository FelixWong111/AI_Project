# P08 评估工具

基于 `p07/system-integration` 的三个模型批处理预测进行独立评分。推理只接收图片及预期数量；只有评估器读取人工真值。每次新建结果目录，不覆盖已有运行。

测试集需自行放置在 `data/test_20261124/`，包括 `images/`、`ground_truth_images.csv`、`ground_truth_objects.csv` 和 `expected_counts.json`；测试数据不随本次代码提交。可用 `--dataset` 指向其他符合合同的测试集。

```powershell
python p08_run.py --dataset data/test_20261124 --model all --output output/p08_runs
python -m unittest discover -s tests -p test_p08_evaluator.py -v
```

`baseline3` 使用 `config/p07.json` 中的尺寸验证版（`size_verified`），其当前冻结配置要求 CUDA 设备 0；实际系统必须安装匹配的 GPU 版 PyTorch。数据处理、UI 和模型版本使用当前 P07 集成配置。不要随意更改已冻结设置。

每个模型输出 `predictions/`（原始预测）和 `evaluation/`（评分）；批次还有三个模型共同可判定图像对照。真值 REVIEW 不参与 PASS/FAIL 评分，模型 REVIEW/ERROR/UNSUPPORTED 另行报告。共同子集由所有模型作出判定的图片构成，可能产生选择偏差。目标级 `object_observations.json` 额外统计包括 REVIEW 图片的输出框/数目，不将 REVIEW 当作 PASS/FAIL；有忽略标注时此辅助统计拒绝运行并记录错误，主评估仍按已说明规则处理。

一号批处理为原始分类器，P07 界面另有场景门控；两者结果不可混为同一指标。本工具不测真实摄像头延迟；三号真实标定、尺寸容差、错规格及目录外识别能力尚待验证。测试集与训练集物理独立性需另行核实。

依赖安装和源码运行见仓库 README；当前工作电脑验证环境包含 Python 3.11.14、PyTorch 2.7.1+cu126、TorchVision 0.22.1+cu126 和 Ultralytics 8.3.236。尚未在全新设备完整重跑。
