每个量重复测量3次，记录量具分辨率、测量人、日期；拍摄能看清卡尺读数和被测平面的照片。

| 实物编号 | 专项实物 | 需要实测的量 |
|---|---|---|
| DIM-SPECIMEN-01 | M4×10细螺丝 | 头型、头下有效长度、总长、螺纹外径、头部厚度 |
| DIM-SPECIMEN-02 | M4×25长螺丝 | 同上，明确“25”对应头下长度还是总长 |
| DIM-SPECIMEN-03 | M4×40异常长螺丝 | 同上，验证异常长度及正常规格的区别 |

还需核对**公共工单使用的实物与专项实物是否相同**。这项关系之前未获确认，并非再次询问“同一专项文件夹内是同一枚实物”。重点是M5：Train H033/H035在多半径头下基准复核后仍约11.6mm，而专项M5的图像测量多为8–9mm。若两批使用不同实物，应分别测量、记录头型和长度定义；不能直接把图像估计强行校正为10mm。

## 2. Camo标定

1. 使用已确认的Camera 0，固定实际使用的镜头、分辨率、数字变焦和裁切；避免采集过程中自动切换镜头。
2. 将真实毫米尺置于零件实际测量平面，采集中心及四角的横、竖方向原始帧；刻度需清晰、有多个已知间隔。
3. 记录实际帧宽高、镜头/变焦、机位工作距离、尺子平面及零件被测面高度。预览图经过窗口缩放，不能作为原始像素尺度。
4. 在P03之外保存原始标定帧，例如 `outputs/camo_calibration_capture/`。可用下面的界面预览和Snapshot保存：

```powershell
python app.py --backend real --model baseline3 --camera 0 --config results/baseline3_v2_experiment/size_repair_v2/p07_profile.json --output-dir outputs/camo_calibration_capture
```

当前照片标定不支持Camo的1280×720视野，因此界面提示尺度不匹配、停止毫米判定是预期行为；不应通过改宽高或打开validated来绕过。采集后建立独立geometry_id，识别真实刻度并验证位置误差，再配置实时管线。

## 4. 新的独立验收

完成物理测量、标定及规格确认后，使用新采集的正常/异常规格实物和摆放场景验收。旧Val、专项66张已使用场景以及已跑Stage 2 Test不得包装成新的独立验证；Stage 3保留集继续封存。验证空台面、缺件、多件、错误规格、额外非目录件、反光/遮挡，以及修改工单不改变实际检测结果。

实际实时延迟另用至少20个新采集帧测量；本轮离线计时不包含手机曝光、Camo传输和GUI渲染。
