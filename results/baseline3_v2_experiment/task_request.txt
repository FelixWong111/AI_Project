# 十、必须计算的评价指标

按照Project Manual及P08现有评价规则，完整计算新旧Baseline3的全部适用指标。

## 10.1 图像级指标

- 测试图片数量。
- 独立场景数量。
- PASS及FAIL的Support。
- Accuracy。
- Balanced Accuracy。
- FAIL Precision。
- FAIL Recall。
- FAIL F1-score。
- TP、FP、FN、TN。
- False PASS数量及比例。
- False FAIL数量及比例。
- REVIEW数量。
- ERROR及其他非成功状态数量。
- Coverage。
- 全部测试样本中的正确判定比例。
- 已成功判定样本中的准确率。

以FAIL为正类：

- TP：真实FAIL，预测FAIL。
- FP：真实PASS，预测FAIL，即False FAIL。
- FN：真实FAIL，预测PASS，即False PASS。
- TN：真实PASS，预测PASS。

涉及REVIEW及ERROR时，按照项目实际规定统计，明确各指标的分母。

不得通过排除失败输入虚增准确率。

## 10.2 目标级指标

分别报告ID0至ID5的：

- Detection Precision。
- Detection Recall。
- Instance Support。
- TP、FP、FN。

使用同类别、一对一、IoU≥0.50的匹配规则。

每个真实目标及预测目标只能匹配一次。

同时记录：

- 正常件漏检。
- 异常件漏检。
- 误检。
- 类别混淆。
- 正常件被错误判为ID0。
- ID0异常件被错误识别为正常件。

如现有训练框架提供mAP，可以作为补充指标，但不得用mAP代替老师要求的独立评价。

## 10.3 计数级指标

- ID1至ID5分别的Count MAE。
- ID0 Count MAE。
- 五类正常件计数向量完全正确率。
- 各类别计数差值错误。
- 实际计数与显示结果的一致性。

Ground Truth数量必须来自非忽略人工标注。

预测数量必须来自真实模型保留检测结果。

不得使用Ground Truth数量冒充预测数量。

## 10.4 工程关键错误

重点统计：

- 不合格工单被错误放行的数量。
- 合格工单被错误拒绝的数量。
- 存在ID0时的False PASS。
- 五类正常件数量完全正确但额外存在ID0时的False PASS。
- 错误规格件被当作正常件的情况。
- 合法工单被大量转换为REVIEW的情况。
- 空白检测平台被错误判为PASS的情况。
- 仅有异常件的工单被错误判为PASS的情况。

## 10.5 尺寸核验指标

在具有可靠真值和独立评价数据的情况下，报告：

- 正常规格件通过率。
- 错误规格件拒识率。
- 尺寸核验失败率。
- 螺丝长度测量误差。
- 直径或其他相关尺寸测量误差。
- MAE及其他具有真实依据的测量指标。

如果不存在可靠实测真值，不得编造尺寸MAE。

如果某项功能缺乏独立评价样本，应标记N/A或NOT_RUN，并说明原因。

图像级异常拒绝成功不等同于尺寸测量准确。

## 10.6 性能及资源指标

报告：

- 模型文件大小。
- CPU/GPU及实际推理设备。
- 输入分辨率。
- Batch size。
- 实际推理设置。
- 离线Inference latency。
- 离线完整Processing latency。
- Median live latency。
- P95 live latency。
- 实际测得的Capture FPS及Processing FPS。
- 内存或显存使用情况，如能够可靠测量。

必须明确区分离线推理、离线完整处理及真实摄像头延迟。
